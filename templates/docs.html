01

Data workspace

The Data workspace is where every analysis begins.

Upload a spreadsheet

  1. Open Data workspace.
  2. Drag a file into the upload area or select Choose file.
  3. Wait for the upload to finish. The dataset loads automatically.
  4. Review its row count, column count, field names, and preview table.
Supported formats: CSV, XLS, and XLSX. Upload and row limits depend on your plan.

Switch datasets

Select any uploaded file from Active dataset. It loads immediately; there is no separate Open button.

Download or delete

Use Download CSV to download the current prepared dataset. Use Delete only when you no longer need the dataset; dashboards attached to deleted data cannot render correctly.

02

Clean your data

Cleaning changes the stored working copy while keeping the workflow simple and formula-free.

Rename columns

Give unclear headings meaningful names before using them in a visual.

Remove columns

Exclude fields that are irrelevant, sensitive, or not useful for analysis.

Handle missing values

Fill missing cells with a selected value or remove incomplete rows.

Remove duplicates

Delete repeated records that could inflate totals and counts.

Remove empty rows

Drop rows that contain no usable values.

Preview before moving on

Confirm the cleaned row count and field names before opening Builder.

03

Dashboard builder

The Builder uses a fixed 16:9 dashboard canvas with a compact view rail and a contextual inspector.

  1. Open Builder and select a dataset.
  2. Select Add visual.
  3. Choose a visual type.
  4. In Data, select the category/X-axis and value/Y-axis fields.
  5. In Build, choose aggregation, sorting, Top-N, or date grouping when available.
  6. In Format, adjust the visual title and presentation settings.
  7. Save the visual, then drag and resize it on the canvas.

Field profile

Select a dataset field to inspect its type, missing values, unique values, and useful summary statistics before choosing it for a chart.

Calculations

Available aggregations include count, sum, average, minimum, maximum, and unaggregated values where the selected visual supports them.

Date grouping

Date-based visuals can group values by month, quarter, or year. Make sure the selected field contains recognisable dates.

05

Pages, layout, and canvas controls

Move and resize

Drag visuals to reposition them. Use the resize handle to change width and height. The 12-column grid keeps the layout aligned.

Dashboard pages

Free dashboards contain one page. Pro supports multiple sheet-style pages, with the visual allowance counted across the complete dashboard rather than separately on each page.

Canvas controls

  • Grid: show or hide layout guidance.
  • Fit page: fit the entire 16:9 page into the available area.
  • Fit width: use the available horizontal space.
  • Actual size: return to 100% scale.
  • Zoom: increase or decrease canvas scale.
  • Focus: hide surrounding controls for more working space. Press Escape to exit.
  • Undo/Redo: reverse or restore recent page and layout changes.
06

Save, reopen, and export

Save a dashboard

Give the dashboard a clear title and save it. Signed-in dashboards remain attached to your account. Anonymous dashboards remain isolated to the current browser workspace.

Open saved work

Open Saved dashboards from the Builder rail. Select a dashboard to restore its dataset, pages, visuals, and layout before its retention deadline.

Exports

  • Cleaned CSV: available from Data workspace.
  • Chart PNG: export an individual visual.
  • Dashboard JSON: Pro export of the dashboard definition.
  • Print/PDF: Pro presentation-ready browser print flow.
07

Accounts and Google sign-in

You can explore anonymously, register with email and password, or continue with Google when Google authentication is enabled.

Continue with Google

  1. Open Account.
  2. Select Continue with Google.
  3. Choose a Google account and approve the basic profile request.
  4. DataViz Dash uses the verified email to create an account or securely link an existing account with the same email.
  5. Your current anonymous workspace is moved into the signed-in account.
Requested Google access: OpenID identity, email, and basic profile. DataViz Dash does not request Google Drive or spreadsheet access.

Email and password

Passwords must contain 10–128 characters and are stored as secure hashes. Signing in restores the datasets and dashboards owned by that account.

09

Privacy and security

  • Uploaded datasets do not receive public share links.
  • Datasets, stored rows, and dashboards are automatically and permanently deleted {{ config.DATA_RETENTION_DAYS }} days after creation.
  • Editing or viewing workspace content does not restart its retention deadline.
  • Users should download or export anything they need before the displayed expiry date.
  • Anonymous workspaces are isolated using a signed browser session.
  • Registered workspaces are owned by the signed-in account.
  • Plan limits are enforced by the server, not only hidden in the interface.
  • Google access and refresh tokens are not stored by the application.
  • Google sign-in accepts only a verified email from a validated OpenID Connect response.
  • Administrative membership and account-status changes are recorded.

10

Troubleshooting

My file will not upload

Confirm it is CSV, XLS, or XLSX and below your plan’s file and row limits. Large or malformed spreadsheets should be simplified before upload.

A field is missing from Builder

Return to Data workspace, confirm the correct dataset is active, and check whether the field was removed during cleaning.

A chart is empty

Check that the selected fields contain compatible values. Use a numeric Y-axis for sum or average, and confirm date values are valid before using date grouping.

I cannot add another page or visual

You have reached the dashboard limit for your plan. Free includes one page and four visuals total.

Google sign-in is unavailable

The deployment owner must configure the Google Client ID, Client Secret, and exact callback URL. Email/password sign-in remains available.

The live site is slow on first open

The Render service may be waking after inactivity. Wait briefly and refresh once.
